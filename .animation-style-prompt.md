# Apex Animation Style Guide & Performance Prompt

Use this document as a reference or a prompt for AI agents to replicate the high-end, elastic, and premium animation language of the Apex platform.

## 1. Core Philosophy

The Apex aesthetic is "Apple-meets-Premium-HealthTech". Animations must feel **deliberate, elastic (not linear), and staggered**. Nothing should simply "appear"; it should arrive with intention.

## 2. Technical Stack

- **Library**: GSAP (GreenSock Animation Platform) + `@gsap/react`
- **Plugins**: `ScrollTrigger`, `TextPlugin`
- **CSS**: Tailwind CSS for micro-interactions and transitions

## 3. The "Elastic Arrival" Pattern

The signature Apex entrance uses GSAP with the `back.out` ease.

### Key Parameters:

- **Ease**: `back.out(1.2)` (standard) to `back.out(1.4)` (dramatic).
- **Duration**: `0.8s` to `1.2s` for major sections.
- **Stagger**: `0.1s` to `0.2s` between items.
- **Direction**: Alternating side-entries (left/right) or slight vertical lifts (`y: 20`).

### Example Implementation (Scroll Triggered):

```javascript
gsap.fromTo(
  ".items",
  {
    x: (i) => (i % 2 === 0 ? -100 : 100), // Alternate side entry
    opacity: 0,
    y: 20,
  },
  {
    scrollTrigger: {
      trigger: ".container",
      start: "top 85%",
      toggleActions: "play none none reverse",
    },
    x: 0,
    y: 0,
    opacity: 1,
    duration: 1,
    stagger: 0.1,
    ease: "back.out(1.2)",
  },
);
```

## 4. Micro-Interactions & Hover States

- **Scale**: Use `hover:scale-105` with `transition-transform duration-300`.
- **Rotation**: Subtle `hover:rotate-2` for images to add playfulness.
- **Blur**: Use `backdrop-blur-md` on overlays and navbars for depth.
- **Feedback**: Smooth background transitions: `transition-all duration-300` or `duration-500` for accordions.

## 5. Specialty Animations

### Typing Effect (Phase 2 Look):

Use `TextPlugin` for typing out headings or highlights.

```javascript
gsap.to(".text-target", {
  text: "Apex",
  duration: 2,
  ease: "none",
});
```

_Note: Pair with a blinking cursor element using a CSS animation._

## 6. Layout & Spacing

- **Grid**: Always adhere to the **8pt spacing system** (multiples of 4px/8px).
- **Shadows**: Use `shadow-inner shadow-white` on containers for a "debossed" card look.
- **Gradients**: Use radial masks for background grids:
  `[mask-image:radial-gradient(ellipse_80%_50%_at_50%_0%,#000_70%,transparent_110%)]`

## 7. Performance Checklist

- [ ] Always use `useGSAP` hook for cleanup and scope.
- [ ] Set `clearProps: "all"` if an animation conflicts with hover states.
- [ ] Use `immediateRender: false` on ScrollTriggered `fromTo` animations to prevent flashes.
- [ ] Prioritize hardware-accelerated properties: `transform` (`x`, `y`, `scale`, `rotation`) and `opacity`.
