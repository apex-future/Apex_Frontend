# Apex

Apex is a modern study companion designed to help you learn faster and smarter. By integrating AI-powered explanations, smart highlighting, and curated educational content directly into your reading workflow, Apex keeps you focused and efficient.

![Apex Landing Page](./public/vite.svg) *Note: Add a real screenshot here later*

## Features

- **Instant AI Explanations**: Highlight any text to get clear, concise explanations without leaving the page.
- **Smart Highlighting & Notes**: Capture insights and build your personal study guide as you read.
- **Built-in Dictionary**: Look up definitions instantly, maintaining your flow.
- **Curated Video Library**: Access expert video explanations relevant to your topic.

## Tech Stack

- **Frontend**: React, Vite
- **Styling**: Tailwind CSS
- **Animations**: GSAP, GSAP ScrollTrigger
- **Icons**: Lucide React

## Getting Started

Follow these steps to set up the project locally.

### Prerequisites

- Node.js (v16.0.0 or higher)
- npm or yarn

### Installation

1.  Clone the repository:
    ```bash
    git clone https://github.com/your-username/apex.git
    ```
2.  Navigate to the project directory:
    ```bash
    cd apex
    ```
3.  Install dependencies:
    ```bash
    npm install
    ```

### Development

Start the development server:

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## Project Structure

- `src/components`: Reusable UI components.
- `src/components/landing-page`: Components specific to the landing page (Hero, Features, etc.).
- `src/assets`: Static assets like images and logos.
